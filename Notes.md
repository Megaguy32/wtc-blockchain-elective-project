### how it work

- ledger: track transaction
- many nodes, identical ledgers
- when transaction, digital signature, announce to all
- all validate transaction, all updates. concensus
- transaction recorded in data - called a block
    in this data,block is mathematical hash
    referencing previous block
- tamperproof history

individual computer doing these validations is called a node.
nodes make up a decentralised network. 
    is a form of peer2peer network
    
- gossip protocol

- if 1 node goes down, all others still have ledger.
